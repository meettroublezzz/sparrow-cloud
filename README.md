# 麻雀云盘

**📌 Work in Progress / 项目施工中...**

欢迎使用麻雀云盘，这是一款**轻量级**的，**开箱即用**的，**使用方便**的个人云盘系统；
以**文件库**为最小的独立存储单元，通过**标签**来检索和管理文件；
拥有**简单权限系统**，支持**分享**、**共享**等基础云盘功能；
存储方式完全以**实际目录结构**为准，**不会拆分文件**。

> 麻雀虽小，五脏俱全

PS：推荐搭配NAS使用
PS：推荐搭配具有**写时复制**能力的文件系统使用，例如：Btrfs、ZFS、ReFS

## 文件库

文件库是**最小的、独立的**存储单元，它不关注用户身份等信息，只聚焦管理文件相关的数据。
它是**相对独立**的存在，不同文件库之间互不影响，各自维护自己的文件、目录、标签、数据库和缓存等。
它不会打乱用户的存储结构，会保留原始的文件目录结构，考虑到灵活和方便，通过**分离**和**附加**实现文件库移动。
它的本质就是一个特殊文件夹，可以像普通文件夹一样放在任意位置、移动或备份。
它可以像普通文件夹一样**打压缩包**或**直接复制**移动到别处，然后**附加**到另一个麻雀云盘系统里即可使用；

#### 文件库示例

它主要的作用是为文件做个整体的分类，方便后续检索与管理；
以下是简单的分类，用户可以按自身情况选择分类。

- 影视库：存放电影、动漫、电视剧等文件。
- 音乐库：存放收藏的歌曲、音乐等文件。
- 小说库：存放收藏的网文、小说、名著等文件。
- 软件库：存放收藏的各类绿色软件、安装包等文件。
- 图片库：存放手机、电脑壁纸等图片文件。
- Album：存放各种照片、录像等图像文件的相册。**PS：不可再生、不能丢失的数据，非常重要**。
- Desktop：存放频繁使用的零碎文件，也用于各端 PC、Phone、Mac、NAS 等中转文件的地方。
- 学习资料：存放各种文本、word、PDF、视频等教程文件。
- “动物世界/学习资料”：懂的都懂，就不展开说了。

PS：文件库支持**隐藏**功能。

## 标签系统

麻雀云盘自带标签系统，搭配关键字搜索，可以非常方便的检索和管理文件。
标签系统仅支持二级标签，**标签分类+具体标签**，这是为了不让文件管理变得过于复杂而限制层级。
每个文件库内的标签系统是**独立的，互不影响**。在不同文件库里，维护各自的标签系统。

通过对标签分类，来管理具体标签，简单高效。

- 角色：大师兄、欧皓辰

【音乐库】
- 歌手：苏念禾、江叙白、温景然、许星瑶
- 专辑：《晚风告白》、《烟火纪年》、《雾中回响》、《星芒序曲》

【小说库】
- 作者：沈清辞、顾砚之、苏晚晴、陆知珩
- 类型：古风仙侠、现代都市、悬疑推理、青春甜宠
